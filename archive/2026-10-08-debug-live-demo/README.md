# Debug Live Demo archive

Archived on 8 October 2026 after the LEARN workshop. Includes the demo pages, JavaScript, CSS, original shared stylesheet and college logo. The alternate synced HTML file is preserved too.

To revisit locally, serve this directory with `python3 -m http.server 4175` and open `http://127.0.0.1:4175/demo/`. The demo is preserved in the website repository. `archive/` is excluded from Cloudflare asset deployment, so the archived files are not published.
